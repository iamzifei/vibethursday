## 三、新功能：问卷（P2，且有前置条件）

| | |
|---|---|
| **要收什么** | 背景 / 人群画像（自由职业·企业主·独立开发·学生上班）、想聊的方向、时间偏好 |
| **为什么不用报名表** | 报名表是**全站最脆的面**（08-11 的判断），而且它要保持「30 秒填完」。这些是多题、有选择题、要结构化的东西 |
| **为什么不用群接龙** | James 08-13 的分工判断（复盘 §14.7）：**单题、要数数、要让别人看得见 → 群接龙；多题、选择题、结构化、私密 → 网站问卷** |
| 🔴 **前置条件** | **先看群接龙回了多少人。** 接龙是零成本的通道测试；接龙都没人回，问卷更不会有人填（历史：报名表反馈栏 3/49 = 6%） |

**已经有一半了**：`availability`（工作日晚上 / 周末白天 / 周末晚上）字段已存在于报名表，
问卷不要重复问它，直接读库。

★ **铁律（复盘 §13.3）：收集必须当场兑现回报。**
收了却没人看到结果，第二次就没人填了。所以问卷**必须配一个只读的聚合展示**
（哪怕只是「这周大家最想聊的三件事」），否则不如不做。
