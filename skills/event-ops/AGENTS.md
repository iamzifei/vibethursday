# 这个文件夹是一个「活动运营」技能

你（AI 助手）被放在这个文件夹里，说明用户要做的是**线下活动的跑单、复盘或迭代**。

**先完整读 `SKILL.md`，再按它执行。** 那份文件是这个技能的全部内容，
本文件只负责在没有原生技能机制的工具里把你指过去。

## 三种常见开场

| 用户说 | 去 SKILL.md 的哪一节 |
| --- | --- |
| 「帮我出跑单」「下周四怎么跑」 | §一 跑单 |
| 「复盘一下」「昨天那场怎么样」，或贴一段当天记录 | §二 复盘 |
| 「下一场改什么」「这个建议要不要采纳」 | §三 已关闭的决策 + §四 迭代 |

## 三条硬规矩（这三条错了，后面都白做）

1. **观察、推断、猜测分开标注。** 拿到现象先写一句「这个观察单独能证明什么」，
   再给解释。每个推断后面跟一句「如果我错了，最可能错在哪」
2. **找设计矛盾，不是执行失误。** 改进措施如果是「下次注意」「加强管理」，
   说明还停在症状层，往下再问一层
3. **动手前先读 `已关闭的决策.md`**（如果用户那边有这份文件）。
   同一个提议每次都被重新提出来，是这类项目最大的时间黑洞

`templates/` 下有三份可以直接抄的：跑单、复盘、已关闭的决策。
